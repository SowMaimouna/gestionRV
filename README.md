# Plateforme de Gestion de Rendez-vous Médicaux - Backend

Ce projet est le backend d'une application de gestion de rendez-vous médicaux. Il permet aux patients de prendre des rendez-vous, aux médecins de les confirmer ou refuser, avec envoi automatique d'emails aux patients.

---

## Technologies utilisées

- Node.js
- Express.js
- MongoDB + Mongoose
- JWT pour l'authentification
- Nodemailer (envoi d'emails)
- Dotenv
- Bcrypt
